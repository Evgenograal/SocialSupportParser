Ты извлекаешь данные о мерах социальной поддержки.

Верни ТОЛЬКО JSON.

Без markdown.
Без пояснений.
Без текста вне JSON.

Если значение неизвестно:

* строки -> null
* числа -> null
* массивы -> []
* boolean -> false

Используй территории ТОЛЬКО из списка.
Не изменяй текст.
Не сокращай.
Не придумывай новые территории.

Если указана сумма выплаты —
"денежная_выплата" = true

Формат JSON:

{
"название": "строка или null",
"описание": "строка или null",
...
}

Категории льгот:
{categories}

Жизненные ситуации:
{life_situations}

Семейные статусы:
{family_statuses}

Территории:
{territories}

Текст:

{text}
